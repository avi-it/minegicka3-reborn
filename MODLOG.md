# MODLOG: Minegicka III Reborn (port of Minegicka III 1.7.10 → Minecraft 26.3 Fabric)

- Original: minegicka3-1.7.10-1.0.0.jar (WilliamEze), CurseForge project 349987, file 2819794.
- Decompiled with Vineflower 1.11.1 to ~/minegicka-decomp/src (NOT in this repo). Behaviour spec: ~/minegicka-decomp/SPEC.md.
- Target: MC 26.3, Fabric Loader 0.19.5, Fabric API 0.162.0+26.3, Loom 1.18.2, JDK 25 (C:/Users/avi/devtools/jdk-25).
- Route: clean reimplementation on Fabric API (no original code or assets shipped). Textures generated by tools/gen_textures.py.
- Oracle: `./gradlew runGametest` (headless GameTestServer, no EULA needed) → SpellGameTests.

## Design
- Spells run server-side in SpellManager (one channelled spell per caster + detached ones).
- Spray droplets are simulated server-side (SprayManager) and replayed client-side from SprayFxPayload, drawn with particles.
- Beams / lightning send LineFxPayload each tick; client draws particles.
- Mana: Fabric data attachment, persistent, synced to owner.

## Gotchas
1. 26.3 renames: EntityTypes (not EntityType constants), GuiGraphicsExtractor + HudElement.extractRenderState, KeyMapping.Category record, PayloadTypeRegistry.serverboundPlay()/clientboundPlay(), KeyMappingHelper.
2. `build genSources` in one Gradle call fails with implicit-dependency validation; run them separately.
3. Test casters must aim at the target (eye height > pig height).
4. Spray droplets must clip fluids (except fire) or cold spray never freezes water.
